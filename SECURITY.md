# Security and data handling

## Reporting a vulnerability

Please avoid opening a public issue for a suspected security vulnerability. Contact the repository owner through the email listed on the [GitHub profile](https://github.com/Parth-Oza) with reproduction steps and expected impact.

## Data policy

This repository is designed for synthetic data. Do not submit employer logs, credentials, access tokens, facility identifiers, maps, customer information, or other confidential operational material.

## Scope

The current project is a local analysis tool with no network or authentication layer. Security reports should focus on unsafe parsing behavior, unintended data exposure, dependency or workflow risks, and documentation that could encourage insecure use.
